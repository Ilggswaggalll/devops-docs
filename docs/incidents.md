# Журнал типовых инцидентов

| Инцидент | Признак | Где искать причину |
| --- | --- | --- |
| Неиспользуемая переменная | Pylint завершился ошибкой | Журнал шага Static analysis |
| Недостаточные права | Deploy не получает OIDC-токен | Журнал deploy-pages и блок permissions |
| Битая ссылка | Сборка MkDocs остановилась | Журнал Build documentation |
| Старая версия после деплоя | На сайте прежний маркер версии | URL окружения, время публикации и кэш браузера |

При разборе фиксируем симптом, причину, исправление и способ проверки восстановления.
